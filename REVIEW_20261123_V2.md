## Detailed Findings

### Statistical Methods ✅
- **Holm-Bonferroni correction**: Correctly implemented in `lega/utils.py` (step-down procedure with proper monotonicity enforcement). None entries are excluded from family size counting.
- **t-distribution usage**: Correctly uses t-distribution critical values via bisection root-finding (`t_critical_95` in `utils.py`), with exponential upper-bound search to handle small df. No hardcoded z=1.96 for small-sample CI.
- **Bayesian analysis** (`bayes.py`): JZS Bayes factor implementation is correct. Prior sensitivity analysis properly reported. Degenerate cases (zero variance, n<2) handled explicitly.
- **Equivalence testing** (`equivalence.py`): TOST implementation uses correct t-distribution critical values with bisection.
- **Permutation tests**: Correct enumeration for small samples, Monte Carlo with fixed seed for larger samples.

### Attention Mechanism ✅
- **Softmax**: All calls explicitly specify `dim=-1` (lines 1203, 1204 of `attention.py`).
- **Null slot handling**: Analytically merged into attention via `sigmoid(a_n - logsumexp(att))`, numerically stable with logsumexp.
- **Causal masking**: Properly applied via `masked_fill_` with `-inf`. Band masking correctly scoped to block boundaries.
- **RoPE**: Correctly applied with pre-multiplication of `1/sqrt(Dh)`.

### Training Loop ✅
- **Gradient accumulation**: `zero_grad()` correctly called at accumulation boundaries; backward within accumulation window is intentional.
- **Gradient clipping**: `clip_grad_norm_` applied after accumulation, pre-clip norm tracked for diagnostics.
- **Non-finite detection**: Proactive NaN/Inf checks on loss with triage routine.

### Data Pipeline ✅
- **Train/test separation**: Properly enforced.
- **Reproducibility**: Hash seed bootstrapping (`bootstrap.py`) ensures deterministic set/dict iteration order across runs.

### Numerical Stability ✅
- Division guards: `clamp_min(1)` or `clamp_min(1e-10)` used throughout.
- Log operations: Epsilon protection via `clamp_min(1e-30)` for entropy computation.
- Overflow protection: Scaling before squaring in `_mean_sd`.
