### Static analysis flag: "P-value without multiple comparison correction" (curves.py)
**Verdict: False positive.**
The code at stats.py lines 962-964 already applies `_apply_holm()` to all three
test families:
- `ctx_tests` (per-context-length paired tests)
- `slope_tests` (ΔEM ~ log2(ctx) slope tests)
- `span_tests` (longest-shortest context span tests)

Each family is corrected independently with Holm-Bonferroni step-down procedure,
which controls FWER under arbitrary dependence. The separation into three families
is methodologically correct: they address different research questions (per-slice
effects, linear trend, endpoint contrast) and pooling them would inappropriately
change the family size for existing per-task corrections.
